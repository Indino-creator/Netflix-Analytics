# Netflix-Analytics
Netflix Dataset Visualisation
- In this porject we will take a netflix dataset from kaggle and will analyse it using the python libraries like  pandas and numpy matplotlib and seaborn 

- This Project analyis netflix content from movies shows and series on the basis of release date runtime ratings genres etc.

TECH STACK 

- Python
- Pandas 
- Numpy 
- Matplotlib 
- Seaborn
- Git and Github 
- jupyter notebook

Datasets 

- There are only Two Datasets
  - Credits.csv
  - Titles.csv

Credits.csv contains the  Person_id, id ,name ,role
Titles.csv contains Titles id etc.

Datasets source - kaggle 
- link - https://www.kaggle.com/datasets/dgoenrique/netflix-movies-and-tv-shows?resource=download
